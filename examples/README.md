# 静态风格示例

这是为开源文档制作的原创静态示例，主题是虚构的“素材助手”。全部界面、文案和图形均为功能示意，不代表真实产品、实际测试结果或客户案例。

下载仓库后，在浏览器打开 [storyboard.html](storyboard.html)。页面无需安装依赖、不加载远程素材、没有动画或音频。

| 文件 | 用途 |
| --- | --- |
| [storyboard.html](storyboard.html) | 三个语义镜头的实际布局与审阅信息 |
| [STORYBOARD.md](STORYBOARD.md) | 详细分镜、建议时间、对象关系与待核查项 |
| [素材来源表.md](素材来源表.md) | 逐项说明原创素材、截图与字体使用 |
| [assets/scene-01.svg](assets/scene-01.svg) | 材料输入：白边贴纸与手绘关系线 |
| [assets/scene-02.svg](assets/scene-02.svg) | 分组展开：同一窗口与对象延续 |
| [assets/scene-03.svg](assets/scene-03.svg) | 结果预览：局部玻璃层次 |

本例无原视频、SRT 或原声，0–12 秒为建议时间。未执行原片核验、逐词校准、动画制作或 MP4 验收。它用于说明仓库效果与交付格式，不是完整视频样片。

本例使用的 SVG/HTML/CSS 与文案按仓库 MIT 许可提供。字体采用本机系统回退，不分发字体文件。
