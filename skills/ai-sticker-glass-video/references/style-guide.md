# 贴纸科普 · 玻璃点缀风格规范

## 风格分工

**贴纸科普为主。** 像干净、易懂的科技杂志：暖浅色画布、深色字、真实产品和结果、可见白色模切边、适量墨线、短标签和手绘箭头。贴纸既要鲜明，又要把对象关系讲清楚。

**玻璃点缀。** 采用弥散渐变与玻璃拟态；产品亮相、设备／浏览器窗口边框、少量身份或地点卡可用半透明面板、柔和局部渐变、轻光感。面板后方只放低细节区域，真实 UI 内部保持清晰；正文和关系线使用稳定高对比底色。

主体镜头以清楚的语义关系和贴纸展开，亮相镜头短暂提高质感后回到解释。无需 80/20 等固定比例，不把整片改成玻璃漂浮卡片、渐变背景轮播、赛博 HUD 或标题幻灯片。

## 基准样式与调整范围

以下尺寸适用于 1080×1920，是起点；其他分辨率按比例调整，最终以手机尺寸审阅为准。

| 项目 | 基准 | 使用约束 |
| --- | --- | --- |
| 画布 | 暖白 `#F6F4EB` | 底纹极淡，不能抢真实图像 |
| 主文字／轮廓 | 深墨 `#203933` | 稳定高对比，正文不要透明 |
| 主强调 | 深绿 `#387957` | 一个系列保持一种主强调；产品品牌明确时可换成其品牌色 |
| 辅助强调 | 暖黄 `#F9CB61` | 用于费用、限制或关键状态；不是每镜必用 |
| 中文字体 | 清楚的无衬线，标题粗体 | 苹方／思源黑体等按环境选取，制作时本地可用并记录来源 |
| 标题／主结论 | 约 72–96 px | 简短，通常不超过两行；不在每镜强塞大标题 |
| 对象／关系标签 | 约 36–54 px | 手机预览仍能认读，注意英文产品名宽度 |
| 白边／墨线 | 白边约 10–12 px，墨线约 3–5 px | 白边轮廓清楚；真实界面不描到内部文字上 |
| 轻倾斜 | 约 3–8° | 对象贴纸可用；操作录屏、长文字和数据表保持端正 |
| 阴影 | 轻短投影或低透明偏移影 | 保持对象落位感，不叠浓重多层发光 |
| 安全区域 | 左右约 80 px，底部约 300 px 起 | 根据原片字幕、脸、手势与目标平台 UI 调整，并在故事板显示辅助线 |

暖白、清晰对象、贴纸语言和局部玻璃是固定风格；强调色、字号、位置随内容和品牌调整。可根据产品品牌选用紫色、深绿或其他强调色，无需沿用示例项目配色。

## 贴纸的四种作用

| 作用 | 可用素材 | 可观察的表达 |
| --- | --- | --- |
| 产品识别 | 核实过的 Logo、产品图、真实 UI 裁切、短名称 | 观众能认出讲的是谁；同一标识跨镜头保持一致 |
| 功能解释 | 浏览器、输入文件、输出结果、源码等对象 | 展开、裁切放大、输入→处理→输出；示意需标注 |
| 状态表达 | 时钟、运行灯、休眠、锁、进度、费用标记 | 原对象发生状态变化，变化依据口播，不随意增加数字 |
| 关系引导 | 箭头、连接线、区域标签、对比容器 | 谁控制谁、谁先谁后、哪个是本地／云端一眼可见 |

贴纸偏少时，先补产品辨识与关键状态，再补关系；不要只加星星、闪电和表情。通常同屏突出两三个语义对象，余下进入辅助层或暂时退出。数量服从阅读，不能作为硬指标。

## 连续叙事与动作

- 先定义可追踪对象，如 `O01=产品窗口`、`O02=本地设备`，保持造型、位置关系和标识一致。语义改变时才重组场景。
- 每次动作用来解释一句话：展开表示能力显露，连接表示信息／控制关系，合盖表示本地停止使用，状态灯继续表示云端仍工作。具体隐喻根据当前稿件判断。
- 进入动作可用约 0.2–0.4 秒短促弹入、轻倾斜落位或箭头描出；其后稳定阅读。不要让所有贴纸一直抖动或循环。
- 关键动作对准原声关键词／重音。句段标注在设计时可用，词级锚点未听核时注明暂定；动作完成后留阅读时间，短段通常约 0.4–0.8 秒起，按实际内容调整。
- 人物画面保持原有曝光、肤色和清晰度，贴纸避开脸、手势、烧录字幕；不默认加全屏压暗罩或重暗角。
- 跨镜头优先保留上一对象接续变化。切回人物要核对原声、表情、手势和字幕。片段尾句未完成时保留继续状态，不擅自补结论或结束卡。

## 真实素材与示意

真实截图／录屏展示实际界面和结果；原创图形展示解释关系。它们可以并置，但不能把示意伪装成真实操作、把痛点窗口误贴成新产品官方界面。

产品界面内部如含不明统计数据，裁掉无关部分或明确为示意；不要因为美观新增完成率、金额、天数、排名或未经验证的宣传结论。
